Des cartes stylées "Roy Lichtenstein"

Qu'est-ce ?

Un outil interactif pour produire des cartes au style "Roy Lichtenstein" d'un lieu quelconque, tableau d'un bout de carte OSM

A télécharger : l'image au format JPG, SVG

A noter : vos images déposées ici et productions ne sont conservées que le temps de votre session, pour vous seuls.

Exemples

Comment ça marche ?

Techniquement, ce petit site web en Python/Flask, un QGis, le tout sous docker.

Lorsque vous validez le formulaire, c'est un bout de script Python qui exploite l'API QGis pour produire la carte, l'archive.

Ce sont les tuiles vectorielles OSM qui sont exploitées + un style QGis maison que voilà : roy.qml

Le code, pas si joli (!), ici : https://github.com/xcaeag/MapAsRoyWeb
